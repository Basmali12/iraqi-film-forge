# تجهيز حسابات Modal سحابياً — تسليم محلي 2026-10-27

تمت إضافة مسار CPU سحابي منفصل عن GPU؛ لا تمر بيانات الأوزان عبر HostHatch. المصدر هو Volume الحساب الأساسي basm1998ali بمسار قراءة فقط، والوجهة Volume مستقل للحساب الجديد. لا يوجد fallback إلى قرص الخادم أو مصدر تنزيل آخر.

الحالة: البرمجة والاختبارات المحلية ناجحة. العامل غير منشور وغير مفعّل بالخادم. لا Volume جديد، ولا نقل أوزان، ولا GPU شُغّل ضمن هذا التحديث. نتائج SDK العابرة للحسابات لم تُثبت سحابياً بعد.

الواجهة:
- إضافة حساب وفحصه وحفظ بياناته مشفرة؛ لا يبدأ النقل من حفظ المفاتيح.
- تجديد التفويض للحساب نفسه دون تغيير هويته أو Volume أو بياناته.
- خطة نقل سحابية وكلفة قبل التنفيذ، وزر اختبار 64KiB مستقل.
- مراحل مستمدة من أحداث العامل؛ الرفع غير محدد النسبة عندما لا يوفّر SDK عداداً. عداد قراءة المصدر ليس نسبة رفع.
- الاختبار الصغير لا ينشئ READY.json ولا يعلن اكتمال النموذج.
- حالة المهمة ومعرف استدعائها محفوظان على الخادم؛ إغلاق الصفحة لا يفقدها.

حماية التنفيذ:
- حجز دائم قبل spawn، ومعرف مهمة ثابت، وتنفيذ واحد فقط؛ الاستجابة المفقودة تصبح uncertain بلا إرسال ثانٍ.
- retries=0، max_containers=1، min_containers=0، buffer_containers=0، scaledown_window=2، لا GPU.
- توكن المصدر لا يُرسل إلى حساب الوجهة. توكن الوجهة يُمرر عبر Modal Secret مؤقت غير مسمى، لا داخل معاملات الدالة أو أحداث التقدم.
- المطابقة باسم الملف وحجمه ثم SHA256 الفعلي. تجاوز الملفات الصحيحة؛ إصلاح الناقص فقط بعد موافقة خطة جديدة. الملف المنقطع يعاد من بدايته لأن SDK لا يوفر كتابة ranged هنا.
- READY.json بعد اكتمال فحص جميع الملفات فقط. التخزين دائم عبر توقف GPU وتغير الشهر؛ لا نقل شهري مجدول.
- الإلغاء لاستدعاء المهمة نفسه؛ لا AppStop للتطبيق المشترك. لا نعلن توقف الموارد قبل انتهاء الاستدعاء وعدد حاويات صفر.

الكلفة التقديرية (CPU فقط، ليست سقف فاتورة):
2 CPU x $0.0000131 + 4 GiB x $0.00000222 = $0.00003508/ثانية.
الاختبار الصغير: 120 ثانية تنفيذ + 180 إقلاع + 2 خمول = نحو $0.01059.
النقل الكامل: 3600 تنفيذ + 180 إقلاع + 2 خمول = نحو $0.13267.
الفوترة الحوسبية على الحساب الأساسي، والتخزين على حساب الوجهة. بناء الصورة والنقل والتخزين والحصص المجانية غير مثبتة لهذه الحسابات؛ الكلفة المسجلة تبقى غير متاحة حتى يرد مصدر موثوق، ولا تُستبدل بالتقدير.
نحو 66.21GiB بسعر قائمة التخزين $0.09/GiB/شهر يساوي نحو $5.96 قبل الحصص والإعفاءات. قد تدخل قراءات التحقق ضمن النقل؛ لا يوجد تأكيد لحصة مجانية.
مراجع: https://modal.com/pricing و https://modal.com/docs/guide/volumes و https://modal.com/docs/guide/dicts

تسلسل الاختبار اللاحق، بعد موافقة منفصلة فقط:
1. نشر عامل CPU في مساحة الحساب الأساسي الموثوق (قد يبني صورة وتخزين حالة):
   .venv-engine\Scripts\python.exe engine\deploy_transfer_worker.py --approve-worker-deploy
   يرفض السكربت مساحة عمل غير basm1998ali ولا يغير profile.
2. بعد نجاح النشر، ضبط ENGINE_CLOUD_TRANSFER_APP=iff-ltx25-cloud-copy-v1 في إعداد الخادم الخاص وإعادة تشغيل آمنة، ثم فحص preflight غير المدفوع.
3. من الواجهة اختيار الحساب الجديد ثم «اختبار نقل صغير» ومراجعة الكلفة والموافقة على اختبار واحد فقط. يقرأ 64KiB من المصدر ويرفعها ويتحقق من بصمتها دون تنزيل النموذج أو GPU.
4. فحص النتيجة والتوقف الفعلي، ثم موافقة منفصلة على النقل الكامل. لا تلقائية بين الخطوتين.
